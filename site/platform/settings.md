# Settings

Open the user menu → *Settings*. Every field is described in [Configuration](/guide/configuration).

## Configuration

![Configuration](/screenshots/en/settings-config.jpg){.shot}

Jellyfin server, the Jellystics plugin card (state, “My statistics” link, history push, resync), data quality and the server time zone.

## Tasks

![Tasks](/screenshots/en/settings-tasks.jpg){.shot}

Run a task now, enable its schedule and edit its cron expression. Import a Playback Reporting TSV export. The task output streams live at the bottom.

## Backup

![Backup](/screenshots/en/settings-backup.jpg){.shot}

Create, upload, download, restore and delete backups.

## Logs

![Logs](/screenshots/en/settings-logs.jpg){.shot}

The last task runs, with search and level filter.

## Webhooks

![Webhooks](/screenshots/en/settings-webhooks.jpg){.shot}

Discord webhooks, the events they receive, and a test button.

## API keys

![API keys](/screenshots/en/settings-apikeys.jpg){.shot}

Keys for Prometheus and other tools. The full key is shown once, at creation.

## About

![About](/screenshots/en/settings-about.jpg){.shot}

Installed and latest version, update check, links to the repository and to the issue tracker.
